Music Player Application 🎵
A fully functional music player built with HTML, CSS, and JavaScript, featuring a sleek UI, playlist management, and audio controls. Perfect for learning core web development concepts while creating a practical project.

✨ Features
🎧 Audio Playback Controls – Play, pause, skip, volume
📁 Playlist Management – Add, remove, and switch tracks
⏳ Progress Bar – Seek through songs
🔄 Shuffle & Repeat – Custom playback modes
🎨 Responsive Design – Works on all devices
🌙 Dark/Light Mode – Toggleable theme

🛠️ Tech Stack
-HTML5 (Semantic structure)

-CSS3 (Flexbox, Grid, Animations)

-JavaScript (Audio API, DOM Manipulation)

-Local Storage (Save playlists)
